# 完善优化验证记录

验证日期：2026-09-14。对应 v1.7.33 的完善优化改动。

## 改动与验证

| 范围 | 结果 | 验证依据 |
|------|------|----------|
| ICMP 响应匹配 | 错误报文中的原始目标地址必须匹配当前请求，防止相同请求编号的其他目标响应干扰检测 | 本地报文回归测试覆盖超时、目标不可达和 IPv4 选项头 |
| RTT | 使用读取到报文的时间计算延迟，排除后续分发和调度耗时 | 三类响应回归测试；旧算法在相同测试中失败 |
| 超时与取消 | 从发送时刻计算截止时间；已取消请求不返回成功；按时到达的排队响应仍有效；发送前的旧响应被忽略 | 发送截止时间、排队响应、取消竞争与旧响应测试 |
| 阻塞发送 | 写入受请求超时及取消约束；取消回调结束后才释放共享发送锁 | 阻塞管道测试覆盖写入截止时间、较早的上下文截止时间、取消及后续发送 |
| 代理响应 | 校验 JSON 后返回原始内容，避免缩进扩容与额外大缓冲区 | 嵌套报文测试：4,097 字节输入不再膨胀为 4,202,498 字节；数字与转义内容保真测试 |
| 配置导入 | 超过 16 MiB 的文件在读取前被拒绝；特殊 JSON 键名完整进入校验；失败保留编辑内容 | 文件读取、未保存状态、特殊地图键名和非法网络键名回归测试 |
| 密码验证 | 导入、导出使用统一 API 地址及超时设置；保留错误密码、限流及网络失败处理 | 实际 HTTP 测试覆盖自定义路径、表单编码、超时、取消和响应状态；页面测试覆盖失败后的控件恢复 |
| 开发代理 | 保留 Host 与 Origin，使同源配置请求通过后端来源检查 | 实际 Vite 代理测试覆盖密码验证、保存路径以及外部 Origin 保留 |
| 浏览器偏好 | 存储不可用时仍可初始化、切换语言和收缩侧栏 | 读取失败、写入失败及正常持久化测试 |
| 监控时间范围 | 正向、反向详情统一使用默认范围；异常设置回退；无效日期不发请求且暂停自动刷新 | 两个详情页覆盖范围上下界、空值、倒置、无效日历日期及已有图表保留 |
| 测试维护 | 自动发现前端测试，忽略已删除测试的旧编译产物 | 临时失败测试验证自动发现和退出码；删除源文件后验证旧产物不执行 |
| 开发说明 | 中英文说明补充本地开发、环境变量、数据目录、导入限制和 Windows Zig race 命令 | 与源码、环境文件及实际执行命令核对 |

## 已通过的检查

- `npm test`：85 项前端测试。
- `npm run lint`：前端静态检查。
- `npm run build:embed`：Vue/TypeScript 检查、生产构建和嵌入资源同步。
- `go test ./src/...` 与 `go vet ./src/...`。
- `scripts/test-race-windows.ps1`：使用 Go 1.27.1、Zig 0.16.0 的完整后端 race 检测；另验证脚本退出后恢复环境变量。
- `CGO_ENABLED=0` 单文件交叉编译：Linux amd64、arm64、armv7，Windows amd64，macOS arm64。
- 最新 Windows 构建运行检查：SPA 页面、7 个入口资源、主要查询 API、缺失采样、密码验证、来源校验、配置保存与重启后的持久化。
- 对 `127.0.0.1` 的实际原始套接字探测：Ping 成功，MTR 10 次发送、0 丢包。此项需要原始套接字权限，已在放宽执行沙箱后验证。

跨平台结果为编译验证，实际进程运行验证在 Windows 上完成。重启持久化检查通过终止并重新启动独立测试进程实现，不将其视为 Windows 优雅退出验证。未部署、发布或修改现有节点的运行配置。

测试和构建使用的缓存、临时运行目录均位于忽略的 `.go-cache` 目录中。正式构建不依赖 Zig 或 CGO；Zig 和附加链接参数仅用于 Windows race 测试。
