## 2026-10-01 告警重试隔离与代理校验开销

- 复现旧告警 MTR 任务取消时重置新规则告警的问题：旧规则进入告警后修改丢包阈值，新规则再次进入告警；旧任务取消会将新告警改为可重试状态，导致下次检查重复报警。修复前的回归测试因此失败。
- 每次进入告警时生成独立标识，排队任务取消、MTR 取消和数据库保存失败只重试对应的告警。规则修改、删除、切换本机地址或健康恢复会使旧标识失效；规则原样重新添加、恢复后再次告警也使用新的标识。仅修改名称或无关配置保留当前标识，允许当前失败任务正常重试。
- 新增回归测试覆盖过期任务取消、规则替换、原样删除重建、本机地址切换、恢复后再次告警、重复使用重试标识、重命名及并发配置更新。原有取消排队任务的重试测试继续通过。
- 代理目标校验直接在配置读锁内读取主机和端口，不再深拷贝全部节点、拓扑及地图。主机和端口来自同一版配置；常见的规范节点键名使用直接查找，别名及不同 IP 写法保留规范化扫描。测试覆盖域名大小写、IPv4 映射地址、IPv6、别名、端口限制、节点移除及并发配置更新。

## 2026-10-04 告警重试状态隔离

- 复现按 IP 恢复重试状态的隔离缺陷：创建旧告警，修改同一 IP 的规则并创建新告警后，旧重试会将新告警状态改为可再次触发。修改前新增回归测试失败，报告旧重试重置了新规则的活动告警。
- 状态转换现在为每次新告警创建独立重试标识，随任务传递至排队、MTR 与存储阶段。取消或写入失败时，仅当前有效标识可以恢复重试状态，并且只能成功使用一次。规则变更、移除、本机切换或健康恢复会清理旧标识；重命名及无关配置变更仍保留有效标识。每个活动目标最多保留一个标识。

## 2026-10-04 报警日期与记录的读取一致性

- 报警接口原先分别执行日期查询和所选日记录查询，两次独立查询之间的采样写入或归档删除可能使响应混用两个数据版本。使用两个真实文件 SQLite 连接，在日期游标关闭后、读取记录前提交写入；修改前回归复现新增当天首条记录却缺少当天日期、归档后日期仍列出却记录已消失，以及读取到日期查询之后改写的记录字段。

- 三项新增回归覆盖六个场景。WAL 模式用独立写连接精确在两次查询之间提交首次插入、归档删除和生产相同形式的 `ON CONFLICT` 更新，确认当前响应保留原快照、下一次请求看到已提交变化。通过实际驱动游标关闭事件同步，不依赖休眠、日志级别或生产测试钩子。
- WAL 和默认 DELETE 日志模式均验证两次查询之间取消后不返回部分 JSON；仅有一个读连接时仍可重新查询，后续写入与正常 API 请求继续成功。默认模式另验证读事务期间写入受到 SQLite 读锁约束，并在响应写入开始时执行第二连接写入，确认锁已释放、后续查询读到新记录。
- 默认日志模式下，读事务会将日期与记录两次读取的锁持有期连接起来，写入可能等待读取结束。事务在 JSON 编码和网络发送前完成，以免客户端发送速度延长锁持有期；未改变生产数据库日志模式、现有写锁或忙等待配置。此轮解决一致性，不宣称查询耗时或吞吐量提高。

## 2026-10-04 在线检测统计的一致性校验

- 在线检测原校验检查数值类型、范围和回复数量不超过发送数量，但会接受未发送探测的成功响应、与计数不符的丢包百分比，以及平均延迟超出最小/最大值范围的统计。新增实际 Vue 页面回归在修改前首先复现零发送、零回复被发布为成功结果。
- 成功响应要求正的发送次数，丢包百分比按 `(发送数 - 回复数) * 100 / 发送数` 的整数商精确校验。有回复时要求 `最小 <= 平均 <= 最大`，仅一次回复时三者相同。仍接受已有安全整数计数范围，使用整数运算避免大计数乘以 100 时的浮点取整错误；例如发送 9,007,199,254,740,991 次、回复 8,106,479,329,266,892 次的数学整数百分比为 9，普通浮点乘除会错误得到 10。该边界用于校验数值准确性，实际节点的在线检测仍固定发送五个探测。
